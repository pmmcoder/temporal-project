Product Requirements Document

飞书审批卡片改版 PRD

针对当前卡片标题栏过重、原始 ID 外露、备注框过高、按钮视觉压力过大和深色模式适配不佳的问题， 定义一版更紧凑、清晰、适合手机审批的交互卡片。

版本 0.1 已确认 · 已实现 更新日期 2026-11-20 暂不修改代码

1. 背景

当前飞书审批卡片已经完成发卡、备注、通过、拒绝、长连接回调和终态更新。业务流程可用， 但实际卡片在飞书深色模式和桌面宽屏下视觉比例失衡。

本次改版只调整飞书 JSON 2.0 审批卡片，不修改 Temporal Workflow、Signal、幂等和审批 API。

2. 改版目标

  • 移动端优先，桌面端保持紧凑。
  • 默认使用低干扰配色，只在状态和主操作上使用强调色。
  • 完整 Workflow ID 和 Run ID 不再进入标题或主摘要区域。
  • 备注输入高度合理，操作按钮并排展示。
  • 通过、拒绝、超时和取消具备清晰的状态差异。
  • 终态卡片完整展示决定、操作人、渠道、时间和备注。

非目标

  • 不增加多级审批、会签或审批链。
  • 不增加附件、图片、文件或富文本编辑器。
  • 不重做控制台 WebUI。
  • 不改变当前飞书长连接架构。

3. 当前问题

标题栏视觉过重

大面积深蓝色 Header 在深色模式下显得突兀，降低正文可读性。

原始 ID 占据主视觉

完整 Workflow ID 和 Run ID 出现在标题下方，内容冗长且对审批人没有直接价值。

备注框高度失控

多行输入框在桌面端占据大半卡片高度，挤压摘要和操作区域。

危险操作过于醒目

拒绝按钮大面积高饱和红色，与通过按钮形成同等视觉压力。

上下文不足

缺少截止时间、状态提示和终态处理信息。

宽屏比例失衡

桌面卡片过宽，表单与按钮没有使用适合宽屏的分组布局。

4. 推荐方案

推荐使用中性灰 Header、单行备注输入、双列等宽按钮和底部弱提示。 Workflow ID 仅在卡片底部显示短码。

4.2 布局规则

区域规则
Header只显示状态和业务标题，中性灰背景。完整 ID 不进入 Header。
摘要支持 Markdown，推荐不超过 500 字。
字段使用两列信息表，移动端自动变单列。
备注单行文本，最大 200 字，占位文案“可选填写审批备注”。
按钮左拒绝、右通过，等宽并排。
调试信息仅底部显示 Workflow 短 ID 和 Run ID 前 8 位。

5.2 已拒绝、超时和取消

  • 已拒绝使用低饱和红色状态。
  • 超时和取消使用中性灰状态。
  • 不展示备注输入和操作按钮。
  • 保留摘要、业务字段、处理时间、渠道和备注。

6. 视觉规范

元素规范
Header中性灰或无色，不使用大面积高饱和背景。
主标题18px 左右，单行优先，最多两行。
状态小面积文本或标签，不抢占标题。
正文13px 左右，行高 1.6。
次要信息11px 左右，使用灰色。
备注输入单行，不设置大面积最小高度。
主按钮使用飞书主题主操作色。
危险按钮低饱和红色背景或红色描边。
圆角使用飞书组件默认值，不额外覆盖。

7. 交互规则

  1. 审批人点击“通过”或“拒绝”。
  2. 备注和决定在同一次 card.action.trigger 回调中提交。
  3. 回调在 3 秒内返回 Toast。
  4. 成功时返回“审批已提交”。
  5. Workflow 完成终态后，使用 message_id 更新卡片。

异常提示

场景提示
非白名单用户无审批权限
参数缺失审批参数不完整
重复操作审批已处理
Signal 提交失败审批提交失败

按钮回调值

{
  "workflow_id": "approvaldemo:key",
  "run_id": "run-1",
  "approval_id": "approval",
  "decision": "approved"
}

8. 验收标准

P0

  • 待审批卡片不再使用大面积高饱和 Header。
  • 完整 Workflow ID 和 Run ID 不出现在 Header 或标题中。
  • 备注输入为单行紧凑控件，不再出现大块空白。
  • 通过和拒绝按钮等宽并排。
  • 移动端和桌面端均无明显文字溢出。
  • 飞书深色模式下正文、输入框和按钮清晰可读。
  • 点击通过或拒绝后 Workflow 能收到正确 Signal。
  • 终态卡片显示决定、操作人、渠道、时间和备注。

P1

  • 底部显示 Workflow 短 ID 和 Run ID 前 8 位。
  • 截止时间按本地时区显示。
  • 通过、拒绝、超时和取消具备不同状态视觉。
  • 卡片更新失败不影响 Workflow 最终结果。

9. 待确认项

1
标题栏

推荐 A：中性灰。可选 B：无 Header；C：保留蓝色但降低饱和度。

2
备注控件

推荐 A：单行文本。可选 B：固定两行；C：保留多行但限制显示高度。

3
按钮顺序

推荐 A：左拒绝、右通过。可选 B：左通过、右拒绝。

4
Workflow ID

推荐 A：底部显示短 ID。可选 B：显示完整 ID；C：完全不显示。

5
控制台入口

手机无法访问本机 127.0.0.1，推荐仅显示提示文本，不生成可点击链接。
